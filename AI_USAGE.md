# AI usage log

The idea for this project was mine: an expense tracker with a monthly budget per category. I built it with help from Claude (Anthropic, Claude Opus 5.5, on claude.ai). I chose the use case and the stack, decided the order of the work, and applied, ran and tested every step myself before committing it. I used Claude to fix and draft the code and the ADR text for each step, to check my results when I wasn't sure, and to help me fix Git problems. I only had two days, so this let me spend my time on understanding each part instead of typing boilerplate.

I ran everything myself, checked it against the brief, and committed and pushed every change myself through pull requests. Infrastructure files (Dockerfiles, compose, workflows) are logged like code, with an explanation of how each one works.
